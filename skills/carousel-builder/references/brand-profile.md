# Brand Profile Guide

Use this guide when the user does not provide a complete visual identity.

## Existing brand

Extract the profile from supplied logo files, colors, fonts, templates, previous posts, or a visual reference. Preserve those choices unless the user asks to evolve them.

## Brand brief

When only a short description is available, ask for these details if they materially affect the result:

* brand or project name;
* audience;
* subject of the carousel;
* desired tone, such as professional, energetic, editorial, playful, or minimalist;
* colors or visual elements to avoid.

Create a concise `BrandProfile.md` containing:

```markdown
# Brand Profile

## Positioning

## Audience

## Tone

## Color palette

## Typography direction

## Layout rules

## Image and icon direction
```

## Guided start

If the user does not know how to answer, create a practical starter profile from the carousel subject and audience. State the inferred choices clearly and ask for confirmation before final PNG generation.

Use accessible contrast, a limited palette, and a legible sans-serif typography direction by default. Never invent a third-party logo or claim an inferred profile is an established brand identity.
