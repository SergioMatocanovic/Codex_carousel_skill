# Carousel Builder

Reusable skill for creating and validating social-media carousel assets from a topic, `Slides.md`, a visual reference, or a brand brief. It can use an existing identity or create a starter visual profile for users who do not have one.

## Skill location

The installable skill is in [skills/carousel-builder](skills/carousel-builder). This is the single source of truth for both Codex and ChatGPT Work.

## Quick help

After installation, write `/skill/help` in a task to receive the installation and usage guide. This is a skill convention recognized by Carousel Builder, not a native slash command in ChatGPT or Codex.

## Two ways to start

**Describe the idea in conversation.** Give the skill a theme, audience, and desired tone. It proposes the slide sequence, creates a `Slides.md` working file after approval, and then produces the carousel.

**Provide `Slides.md`.** This optional Markdown file is a screenplay for the carousel. Use it when you want to define the exact slide order and copy before generation. Start from [the complete seven-slide example](skills/carousel-builder/examples/Slides.example.md).

## Brand profile

Choose one of three paths before generation: provide an existing visual identity, describe the business and desired tone, or ask the skill to create a starter profile. When it creates the profile, it proposes the color palette, typography direction, layout rules, and image direction in `BrandProfile.md` for approval before final PNG generation.

## Theme-led image generation

The standard workflow does not reuse a fixed visual model. It creates a `visual-plan.json` for the subject, then uses ChatGPT Images 2.5, when available in the workspace, to generate text-free source imagery that matches the plan. The compositor adds the exact carousel text, so the final slides do not depend on image-generation text accuracy.

In ChatGPT Work, use the native image generator available in the conversation. This skill does not require an API key, API configuration, or separate API billing.

## Canvas selection

The skill asks for one format before generation:

| Command value | Format | Size |
| --- | --- | --- |
| `vertical-principal` | Vertical Principal | 1080 x 1440 px, 3:4 |
| `vertical-classic` | Vertical Classic | 1080 x 1350 px, 4:5 |
| `square` | Square | 1080 x 1080 px, 1:1 |

Vertical Principal is the recommended format.

## Install in Codex

Ask Codex to install the skill from this repository using the path `skills/carousel-builder`. The installer places it in the local Codex skills directory and it becomes available in the next task.

## Install in ChatGPT Work

Create a ZIP containing the contents of `skills/carousel-builder`, with `SKILL.md` at the ZIP root. Then go to **Plugins → Skills → Create → Upload from your computer** and upload the ZIP. After the scan, install or share it from the Skills page.

## Requirements

Use Python 3.10 or later and install the dependencies from the skill folder:

```bash
python -m pip install -r skills/carousel-builder/requirements.txt
```

## Local usage

```bash
python skills/carousel-builder/scripts/parse_slides.py Slides.md \
  --output-json parsed-slides.json

python skills/carousel-builder/scripts/create_image_prompts.py \
  --parsed-json parsed-slides.json \
  --visual-plan visual-plan.json \
  --output image-prompts.md

# Generate the listed, text-free images in ChatGPT Images and save them in generated-images/.

python skills/carousel-builder/scripts/compose_theme_carousel.py \
  --parsed-json parsed-slides.json \
  --visual-plan visual-plan.json \
  --image-dir generated-images \
  --output-root "Social Media/Instagram/Carousel Series" \
  --mode create \
  --format vertical-principal \
  --output-json generation-report.json

python skills/carousel-builder/scripts/validate_carousel_output.py \
  "Social Media/Instagram/Carousel Series" \
  --parsed-json parsed-slides.json \
  --format vertical-principal \
  --output-json validation-report.json
```

`Description.md` is the only caption file generated by the workflow. Word documents are intentionally not created or required.

## Output history and revisions

The output root contains one `historico.md` file and one directory per carousel:

```text
Carousel Series/
  historico.md
  Carousel 1/
    Description.md
    slides/
    generated-images/
```

`historico.md` records the creation date, last update, theme, slide count, and status. To change an existing carousel, keep its number and use revision mode. The existing folder, description, slides, generated images, and history entry are updated in place.

```bash
python skills/carousel-builder/scripts/compose_theme_carousel.py \
  --parsed-json corrected-slides.json \
  --visual-plan corrected-visual-plan.json \
  --image-dir corrected-images \
  --output-root "Social Media/Instagram/Carousel Series" \
  --mode revise \
  --carousel 1 \
  --format vertical-principal
```
